# Research Project Template

This repository provides a reproducible and structured template for empirical research projects.
It is designed to be cloned or used as a template for each new paper or research project.

The template supports:

- Pre-study documentation, pre-analysis plans, and preregistration
- Reproducible data analysis in R
- LaTeX / Overleaf manuscript writing
- Optional OSF documentation
- Claude Code project skills for research workflows

## 1. Intended Use

### One repository = one research project

For each new paper or research project:

1. Use this repository as a template.
2. Rename the repository to the project name.
3. Open the `.Rproj` file in RStudio.
4. Work only inside the cloned project folder.

GitHub is the source of truth. Overleaf and OSF are interfaces, not primary storage.

## 2. Folder Structure

```text
.
|-- .claude/
|   `-- skills/                 # Claude Code project skills
|-- prestudy/
|   |-- paper/                  # LaTeX pre-study / preregistration text
|   |-- R/                      # Power analysis and randomization templates
|   `-- masterfile_prestudy.R
|-- R/                          # Main analysis scripts
|-- data/
|   |-- raw/                    # Raw data; never modified and not committed
|   |-- interim/                # Intermediate data; not committed
|   |-- processed/              # Cleaned analysis data
|   |-- simulated/              # Simulated or demonstration data
|   `-- final/                  # Final export data; not committed
|-- output/
|   `-- models/                 # Saved model objects or diagnostics
|-- paper/
|   |-- sections/               # Manuscript sections
|   |-- figures/                # Figures generated by R
|   |-- tables/                 # Tables generated by R
|   |-- bibliography.bib
|   `-- main.tex
|-- OSF/                        # OSF-related documentation
|-- masterfile.R                # Runs the full analysis pipeline
`-- README.md
```

## 3. Typical Workflow

### Step 1: Create a new project

- Use this repository as a template.
- Rename the repository, for example `energy-feedback-rct`.
- Open the `.Rproj` file in RStudio.
- Initialize a reproducible package library and commit the lockfile:

```r
renv::init()
```

### Step 2: Optional pre-study / preregistration

- Fill in the files in `prestudy/paper/`.
- Adjust power simulations in `prestudy/R/`.
- Run the pre-study pipeline:

```r
source("prestudy/masterfile_prestudy.R")
```

- If required, use `OSF/` to prepare preregistration documentation.

### Step 3: Data analysis

- Place raw data in `data/raw/`.
- Never edit raw data directly.
- Implement data loading in `R/01_load_data.R`.
- Implement cleaning in `R/02_cleaning.R`.
- Run the full pipeline:

```r
source("masterfile.R")
```

The pipeline runs:

1. `R/00_setup.R`
2. `R/01_load_data.R`
3. `R/02_cleaning.R`
4. `R/03_descriptives.R`
5. `R/04_analysis.R`
6. `R/05_tables_figures.R`

### Step 4: Revisions (R&R)

For a revise-and-resubmit, create `revision/round_<n>/` containing:

- `response_letter.tex` — the point-by-point response to reviewers.
- `changes.md` — a table mapping each reviewer point to the change made and its location.

See the `referee-response.md` reference in the economics-paper-writing skill.

## 4. Data Policy

- `data/raw/` is for original data only. It is ignored by Git except for `.keep`.
- `data/interim/` and `data/final/` are ignored by Git except for `.keep`.
- `data/processed/analysis_data.csv` is included as example output for the template.
- Do not commit confidential, proprietary, or personally identifiable data.

## 5. Claude Code Skills

Project-specific Claude Code skills live in `.claude/skills/`.

Start Claude Code from the project root:

```powershell
claude
```

Then ask Claude:

```text
What skills are available?
```

The included skills cover R pipelines, causal inference, theory modeling, OSF/preregistration, LaTeX paper writing, economics paper writing, multi-agent research collaboration, mentoring/learning, and the project log & to-do workflow.

## 6. Agent Workflow Files

- `CLAUDE.md` — always-loaded guidance for AI agents: hard rules, model routing, plan adherence, and the skill map.
- `AGENT_LOG.md` — append-only, machine-oriented log shared by all agents.
- `TODO.md` — human-readable to-do list (source of truth for tasks). Regenerate the paper's to-do appendix with `source("R/99_generate_todo_annex.R")`.
- `internal/` — the user's private knowledge base (methods notes, decisions). Not part of the paper.
- `paper/sections/99_todo_annex.tex` — auto-generated colored to-do table shown as an appendix in the compiled PDF.
