# Referee Response (R&R)

Conventions for response letters to reviewers.

- Open with a brief, single thank-you. Do not over-apologize.
- Reproduce each reviewer point verbatim (quoted or italicized), numbered, and respond directly beneath it.
- Every response says **what changed and where** (section, page, table). If nothing changed, explain why, with evidence.
- Disagree politely and with evidence, never dismissively. Reviewers may still be right in part — concede what is fair.
- Maintain a short **summary-of-changes** page for the editor at the top.
- Never claim a change that was not actually made in the manuscript. Cross-check each "we now do X" against the current draft.
- Keep a `revision/round_<n>/changes.md` mapping reviewer point → change → location, so the letter and the manuscript stay in sync.

Structure:
```
Summary of main changes
Reviewer 1
  1.1 <quoted point> → response + location
  1.2 ...
Reviewer 2
  2.1 ...
```
