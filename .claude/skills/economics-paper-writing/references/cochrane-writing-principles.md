# Cochrane Writing Principles For Economics Papers

Source: John H. Cochrane, "Writing Tips for Ph.D. Students" (2005), distilled into reusable manuscript guidance.

## Contribution And Organization

- Identify one central, novel contribution and write it in one concrete paragraph.
- Organize the paper like a newspaper: main result first, details later.
- Do not write a paper as the chronological story of the research process.
- Remove material before the main result unless the reader needs it to understand the main result.
- Use appendices for robustness checks, extended models, and secondary discussions that are useful but not central.

## Abstract

- State the main contribution and result.
- Be concrete.
- Do not summarize the literature.
- Do not say only that data are analyzed or theories are tested.

## Introduction

- Start with what the paper does and finds.
- Give the fact, estimate, mechanism, or design behind the conclusion.
- Avoid broad philosophical openings and generic policy motivation.
- Keep it short.
- Roadmap paragraphs are optional, not mandatory.

## Literature Review

- Put literature after the contribution is clear.
- Focus on the closest papers and priority claims.
- Be generous; the paper does not need to diminish others to be valuable.
- Remove citation clutter in later drafts.

## Body

- Reach the central result quickly.
- If theory supports an empirical paper, present only the model needed to understand the empirical work.
- Start empirical sections with the main result, then add intuition, stylized facts, criticisms, and robustness.
- Conclusions should be short and should not repeat the whole paper.

## Documentation And Reproducibility

- A careful reader should be able to reproduce each number from the paper, appendices, and code.
- Explain how central tables, standard errors, simulations, and samples are constructed.
- Simpler methods are better when they answer the question.

## Footnotes

- Do not use footnotes for parenthetical comments.
- Put important points in the text.
- Delete unimportant points.
- Use footnotes for genuinely skippable details such as algebra, citation lists, or documentation.

## Tables

- Captions should let a skimming reader understand the table.
- Regression table captions should identify the dependent variable, key regressors, and specification.
- Discuss every number or pattern shown.
- Round to meaningful precision.
- Use units readers can interpret.

## Figures

- Captions should be self-contained.
- Label axes.
- Use readable line styles.
- Use figures for patterns that tables hide.
- Define symbols near where readers need them.

## Sentence-Level Editing

- Use active voice.
- Use present tense unless chronology matters.
- Use normal sentence structure.
- Prefer concrete language over abstraction.
- Replace technical jargon when ordinary language works.
- Remove throat-clearing phrases such as "it should be noted that."
- Avoid unsupported adjectives such as "striking" or "very novel."
- Replace vague "this" with a specific noun phrase.
- Use hyphens consistently for compound modifiers.
- Spell out author names rather than using shorthand initials.

## Empirical Identification Checklist

- State the causal claim.
- Identify the economic mechanism that creates variation in the right-hand-side variable.
- Identify the economic mechanism represented by the error term.
- Explain why the key variation is plausibly unrelated to the error term.
- Explain why instruments affect the endogenous regressor but not the outcome except through that regressor.
- Distinguish controls from instruments.
- Describe which variation drives each estimate, especially when adding fixed effects.
- Check reverse causality and omitted common causes.
- Avoid controls that block the mechanism of interest.
- Explain economic magnitude, not only statistical significance.
- Report standard errors for important estimates.

## Seminar Or Slide Version

- Get to the main contribution quickly.
- Use slides for equations, tables, figures, and essential definitions.
- Avoid long literature review and result previews.
- Leave enough time for the audience to read each slide.
- Listen to questions fully before answering.
