# LaTeX Paper Workflow

## Project Structure

Relevant files and folders:

- `paper/main.tex` is the main manuscript.
- `paper/preamble.tex` contains LaTeX setup.
- `paper/titlepage.tex` contains title and author information.
- `paper/sections/` contains manuscript sections.
- `paper/tables/` contains tables generated by R.
- `paper/figures/` contains figures generated by R.
- `paper/bibliography.bib` contains references.

## Instructions

1. Read `paper/main.tex` before changing section files.
2. Keep generated tables and figures in `paper/tables/` and `paper/figures/`.
3. When changing empirical claims, check the corresponding R output first.
4. Do not invent numerical results. Pull them from generated outputs or R objects.
5. Keep LaTeX changes scoped and compile-aware.
6. If adding references, update `paper/bibliography.bib` and cite with stable BibTeX keys.

## Writing Guidance

- Use concise academic prose.
- Keep methods, data, and empirical strategy consistent with the R scripts.
- Mark uncertain or placeholder claims clearly instead of presenting them as final results.
- Prefer small, reviewable edits to manuscript sections.
