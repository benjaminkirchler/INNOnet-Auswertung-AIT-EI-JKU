# Internal Notes

The user's private knowledge base for this project. Not part of the paper.

Use this folder to record:
- `methods_notes.md` — explanations of methods, why an estimator/model was chosen.
- `decisions.md` — dated log of non-obvious project decisions and their rationale.
- Domain facts, data quirks, and things learned while working.

Agents should offer to add a note here when a non-obvious choice is made or the user
teaches the agent a project-specific fact (see the `mentor-and-learning` skill).

Keep entries short and dated. Do not store credentials, tokens, or private data here.
